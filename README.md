## The line

> My boss calls it "wearing many hats"; I call it five job descriptions and one salary.

## Why it works

The joke takes a familiar management euphemism — "wearing many hats" — and answers it with unfair arithmetic: five job descriptions, one salary. The setup is a phrase every office worker has heard from a boss; the punchline reframes it as exploitation, and the contrast between "five" and "one" is the whole laugh. It needs no explanation, it lands on one read, and it avoids the tired office cliches (no meetings-that-could-have-been-emails, no printers, no "per my last email"). Every word earns its place.

## How it runs

`main.py` (Python 3.13, standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), deterministically — the same bytes on every run.

```sh
python3 main.py
```
